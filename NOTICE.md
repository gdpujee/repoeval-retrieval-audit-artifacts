# Data and code provenance

The RepoEval retrieval data and repository snapshots originate from the
CodeRAG-Bench project at the pinned revision documented in `README.md`.
CrossCodeEval inputs originate from the Amazon Science `cceval` project at the
pinned revision documented there. This repository does not vendor either
upstream project. Their original authors retain rights in their data and code;
this release does not relicense third-party material appearing in derived
contexts or outputs.

The saved generation outputs were produced through the model provider APIs
described in the manuscript. Their provenance, model names, and limitations
are recorded in the result files and reproduction instructions.
